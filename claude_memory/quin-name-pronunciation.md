"Quin" is pronounced **kwin**; the owner settled this on 2026-10-29.

**Why:** in some accents "Quin" drifts toward "queen" or "keen", which matters for voiced lines.

**How to apply:**
- Every voice line, announcer line and phonetic hint uses "kwin".
- The plural is "Quins".

The projectile jump's name is still the owner's call:
- "PJ" reads as pyjamas to Americans, and "projectile" brings up "projectile vomit".
- Suggested names: Lark, Pounce, Skyshot, Comet, Slingshot, Launch.
- Avoid "rocket jump".
