On 2026-10-24 the owner said the world's look and the new-player flow are placeholders on purpose: "these are all designs, it's fine, i intended it this way for now because i wanna make sure that the core game loop is good already". They estimate the project at about 50% done.

Placeholders covered:
- the spawn facing away from the terminals;
- grey, unlabelled terminal blocks;
- no guide arrow or welcome card.

**Why:** the core loop has to feel right before the world gets dressed.

**How to apply:**
- Don't propose spawn, signage or onboarding fixes as blockers. Park them for a later polish/onboarding pass.
- Judge work by whether the core loop holds: own, register, prep, spectate, results, maintenance, repair, repeat.
